# Devika Gaikwad — Portfolio

A personal portfolio built with Next.js, React, TypeScript and CSS. It presents
Devika's background, skills, internship experience, education and projects.

## Features

- Responsive layout with light and dark themes
- Animated developer-role text
- About, skills, experience, projects, education and contact sections
- Downloadable resume
- Links to GitHub, Naukri, email and phone

## Getting started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run lint
npm run build
```
